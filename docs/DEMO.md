# 演示指南

## 日常展示（约5分钟）

1. Gateway 已运行后启动 `start.cmd`，打开本项目网页 18890。
2. 说明这是个人原型，全部模拟资料，不代表某培训公司的真实规则。
3. 选“零基础试听咨询”，勾选模拟数据与费用确认。
4. 开始运行，展示主管、招生、课程、主管四个阶段。
5. 展开执行证据：不同 Agent、独立 session、OpenClaw run ID 和耗时。
6. 查看“基础班”初步建议和未知价格/排课；说明最终分班需教练评估。
7. 编辑家长回复，勾选审核、确认审核。强调“已审核 / 未发送”。
8. 导出 JSON，展示可以作为未来 CRM 适配器的输入。

## 第二场景

选择“教练反馈”。输入6周训练周期但没有历史成绩，检查输出没有捏造“六周进步百分比”或伤病判断；它只能总结本节观察。

## 边界展示

“信息不足”案例应列出待补充信息，不凭空推荐具体时间。“指令注入”案例用于演示规则边界，不代表整个系统已通过安全认证。

## 网络失败备用

点“查看历史演示”。必须主动说明它是之前的真实运行记录，不是现场调用。回放不产生费用，也不允许将它当作新任务审核。

## 启动注意

官方控制台18789和本项目18890是两套网页。官方 Gateway 需要持续运行；start.cmd 的原型服务器窗口也需要保持开启。关闭原型服务器窗口只停止本项目界面，不删除数据。

重启电脑后先启动 OpenClaw Gateway（本机可用运行时）：

```cmd
"%USERPROFILE%\.openclaw\runtime\node-v26.10.0\openclaw.cmd" gateway run --bind loopback --auth token
```

保持该窗口，再启动 start.cmd。其他安装位置请使用正常的 `openclaw gateway run`。
