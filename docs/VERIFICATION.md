## 联调中发现并修正的问题

- 当前 OpenClaw 在 Gateway 运行时禁止 agent --local，改为 CLI → Gateway，不停用已有助手。
- 模型有时把年龄写成字符串，增加明确类型提示和无损年龄表示转换；仍不合规则终止，不补造业务事实。
- 原型服务器重启后立即测试曾出现连接拒绝，测试脚本改为等待健康接口就绪。
- 公开文件扫描增加测试样本豁免，避免把虚构规则测试数据当成密钥；扫描仍需人工审核。
- 浏览器未捕获原Blob导出事件，改为服务端Content-Disposition附件后下载验证成功；修改过的草稿必须先审核保存，避免导出未保存修改。
